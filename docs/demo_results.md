# Executed synthetic demonstration

The following results were generated by running `python scripts/demo.py --output
demo_output` on 25 October 2026 (America/Vancouver). They demonstrate the software;
they are **not findings about real patients**. The input is the supplied
deterministic synthetic dataset, generated with seed `20261026`.

## Data and analysis decisions

| Item | Result |
|---|---:|
| Rows in uploaded example | 504 |
| Duplicate rows explicitly removed | 4 |
| Rows in the cleaned dataset | 500 |
| Linear model complete cases | 434 |
| Linear model exclusions for missing required values | 66 |
| Logistic model complete cases | 429 |
| Logistic model exclusions for missing required values | 71 |
| Logistic model events (`Yes`) | 125 |
| Logistic model non-events (`No`) | 304 |

The model candidates were age, BMI, sex, smoking, and severity. Reference
categories were Female, Never, and Mild. Severity was ordered Mild → Moderate →
Severe for display and was represented by two indicator coefficients in the
regression. No imputation, outlier removal, or automatic category merging was
used. The two outcomes were analyzed separately.

Both p < 0.05 screening lists contained age, BMI, smoking, and severity. For the
linear outcome, the p < 0.25 list contained all five candidates. For the logistic
outcome, its p < 0.25 list contained age, BMI, smoking, and severity; sex was then
manually retained to demonstrate how a prespecified variable can be included
regardless of its screening p-value. Screening was based on each whole variable's
joint test, including both indicators of a three-level predictor.

## Linear regression

Outcome: simulated blood pressure. The model used ordinary least squares with
HC3 covariance and t-based confidence intervals. R² = **0.364711**; adjusted
R² = **0.352753**. It contained nine parameters, including the intercept.

| Predictor or contrast | Adjusted coefficient | 95% CI |
|---|---:|---:|
| Age, per year | 0.505 | 0.424 to 0.586 |
| BMI, per unit | 0.729 | 0.483 to 0.975 |
| Male vs Female | 3.492 | 1.124 to 5.859 |
| Nonbinary vs Female | -0.669 | -10.318 to 8.980 |
| Current vs Never smoking | 6.236 | 3.162 to 9.310 |
| Former vs Never smoking | 2.870 | 0.175 to 5.565 |
| Moderate vs Mild severity | 4.553 | 2.019 to 7.087 |
| Severe vs Mild severity | 11.020 | 7.351 to 14.688 |

For example, conditional on the other modeled variables, a one-year age
difference was associated with a 0.505-unit difference in the mean synthetic
outcome (95% CI 0.424 to 0.586). This describes the simulated association; it
does not establish a causal effect.

The diagnostic check flagged 23 observations above the exploratory Cook's
distance threshold 4/n. The software reported the flag and retained every such
observation. A threshold flag is a reason to inspect observations in context,
not an instruction to delete them.

## Binary logistic regression

Outcome: simulated event, with `Yes` coded as the event. Maximum-likelihood
estimation converged. McFadden pseudo-R² = **0.098474**; AIC = **484.719**.
Apparent AUC = **0.706974**, and apparent Brier score = **0.182141**. These
performance values use the fitting sample and are not validation results.

| Predictor or contrast | Adjusted odds ratio | 95% CI |
|---|---:|---:|
| Age, per year | 1.046 | 1.027 to 1.066 |
| BMI, per unit | 1.029 | 0.983 to 1.077 |
| Current vs Never smoking | 2.309 | 1.334 to 3.997 |
| Former vs Never smoking | 1.289 | 0.756 to 2.198 |
| Moderate vs Mild severity | 2.104 | 1.293 to 3.424 |
| Severe vs Mild severity | 2.703 | 1.374 to 5.317 |
| Male vs Female | 1.420 | 0.901 to 2.237 |
| Nonbinary vs Female | 2.523 | 0.586 to 10.858 |

For example, the adjusted odds ratio for Current versus Never smoking was 2.309
(95% CI 1.334 to 3.997), conditional on the other modeled predictors. The number
is an odds ratio, not a risk ratio. The wide interval for the smaller Nonbinary
group illustrates why precision should be reviewed alongside a point estimate.

All intervals and p-values are nominal. They do not adjust for the exploratory
selection procedure, and the example does not justify a clinical conclusion.

## Outputs and verification

The executable demo writes overall and stratified Table 1, the bivariate
estimates and screening tables, both adjusted models and joint tests, VIF,
an Excel workbook, machine-readable summaries, cleaning/analysis logs,
distribution/forest/diagnostic figures in PNG and SVG, and one result ZIP per
model. Each model ZIP contains its own model results and the shared descriptive
tables; the combined workbook contains both models.

Run `python -m pytest -q` to execute the included tests. The statistical tests
were executed during development and included independent analytic/reference
checks, model failure cases, and missing-data and cleaning behavior. The
[validation record](validation.md) provides the executed suite count, including
UI and export checks.
